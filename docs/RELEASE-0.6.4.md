# OFMtouch v0.6.4 — Manager Progression & Planning

Build a stronger managerial career with achievements, saved milestones and clearer planning tools.

## Career rewards

**More → Achievements** is available alongside Training and Academy, including between clubs. Ten one-time goals reward managing matches, victories, trophies, promotion, board objectives, player development, youth minutes and career longevity. Earn 1,700 XP across the full set and progress from level 1 to level 6.

Every earned level adds 2% training growth, capped at 10%. Match composure, decisions and teamwork receive up to +2; these bonuses affect match simulation without rewriting permanent player attributes. Each new level celebrates with +2 morale for the current team, capped at 100. Rewards persist with the manager and cannot be reclaimed by reloading. Newly met goals are recorded on date advancement. Youth minutes count completed matches at the managed club after this update; transferred players do not bring minutes earned elsewhere.

## All 16 additions

1. Three rotating, consistent save backups and explicit recovery after a failed load. Restoring discards progress since that backup and preserves the failed save separately.
2. Android Back closes More; keyboard focus stays in the sheet and returns when it closes.
3. Faster daily training staff lookup, with the same underlying coaching formulas.
4. Transfer fee plus first-year wages and remaining weekly wage capacity before bidding.
5. Playing-time promise deadlines, remaining matches and injury pauses.
6. Side-by-side shortlisted player comparison, including ability, potential, wages and formation fit.
7. A six-month squad plan showing the coverage lost if expiring contracts are not renewed.
8. Saved monthly academy reviews, development changes and senior-promotion guidance.
9. Visible matchday substitutions and tactical shortcuts, with commands serialized against simulation steps.
10. A decisions inbox that keeps unresolved choices visible and puts urgent decisions first.
11. Individual monthly development goals measured against saved training reviews.
12. Loan monitoring for minutes, development, return dates and unused players.
13. Cash and wage forecasts over 4, 12 and 26 weeks, including agreed future registrations.
14. A persistent manager timeline for match totals, wins, trophies, promotions and anniversaries.
15. Stronger high contrast, saved reduced motion including charts, and mobile pinch zoom.
16. Manager achievements, XP, levels and capped team benefits in More.

Forecasts use current recurring cash flow and agreed registrations. Future match income, contract expiries and loan returns can change the result. Legacy milestone dates are labelled as earlier career progress rather than inventing exact dates.

## Install

Android ARM64. Install the signed APK over the existing OFMtouch app to retain saves. The package name and release certificate remain unchanged; the Android version code increases. Matching GPL source and SHA-256 checksums accompany the release.

A physical-device install and gameplay session still require device verification; automated tests and package/signature verification do not replace that check.
