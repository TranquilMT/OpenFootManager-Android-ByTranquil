# 0.7.3 release validation

The release follows 200 development commits. The approved-scope ledger retains incomplete proposals; this release does not claim all proposed features are finished.

## Quality guard review

The initial full preflight passed formatting and standard lint, then rejected stale file-size and debt counters. The updated baseline explicitly accounts for regression tests added to the existing turn, inbox, squad, match, youth and numeric-helper suites, and the integrated match controls added to MatchLive, SubPanel and PostMatchScreen. The canonical-position helper is reused from the squad feature so imported roles behave consistently; that deliberately adds one measured cross-feature dependency.

New avoidable lint findings were corrected: event filters use a native fieldset, the redundant substitution-panel fragment is removed, and four test-fixture non-null assertions are removed. The baseline retains every existing guard and records reduced accessibility/non-null debt. It does not disable lint rules or exclude new production files. Further large-file decomposition remains technical debt.

## Release gates

- Dependency audit: the full audit found four vulnerable development dependencies. Compatible updates to nanoid, smol-toml, source-map-js and undici remove the findings; production dependencies were already clear. The Android release workflow now requires the full audit.
- Full frontend preflight: passed formatting, lint, quality, portraits, production build and all 1,896 tests across 242 files after release metadata changes.
- Translation audit: all 12 supported locales match the English key set.
- Rust workspace tests and Clippy: checked through GitHub CI on the exact release source.
- Android package, version 0.7.3, monotonic version code 7300362, ARM64 payload, alignment and original persistent signing certificate: required before publication.
- Matching source archive and SHA-256 checksums: required before publication.
- Physical-device installation and gameplay: not performed in this session; reported separately from automated/package validation.
