## Completion rules

Each proposal needs a working integration and applicable tests or an explicit verified existing implementation. Related changes may share infrastructure, but features must not be marked complete merely because a helper or UI placeholder exists. Audit proposals need recorded results and fixes for findings. Physical-device validation must be reported separately from automated/package checks.
