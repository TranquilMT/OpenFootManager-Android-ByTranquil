# OFMtouch 0.7.3 — approved implementation scope

Approved on 8 October 2026. Target: 200 meaningful development commits covering these 200 proposals, with integrated gameplay, all locales, old-save compatibility and regression evidence. A commit count is not evidence that a feature is complete.

Baseline: released 0.7.2 Build 361 (`9b6b8154214456cd6a4a75b83175cee35eccff87`). Development branch: `feat/0.7.3-integrated-gameplay`, created from current `main` because this Android repository has no `develop` branch.

Status: development in progress; no 0.7.3 APK or release published. Preserve the existing Android package and persistent release signing certificate. Required deliverables: signed APK, complete matching source ZIP, SHA-256 checksums, release manifest, README and translated release notes.

## Evidence recorded so far

- Commands queue behind simulation snapshots instead of being silently discarded; 5 operation-gate tests pass.
- Shared bench filtering excludes dismissed, used, duplicate and active players; substitution recommendations respect remaining allowance.
- Recommendations protect reserve goalkeepers; prepared substitutions revalidate current selections.
- Tactical adjustments remain available after the final substitution; 10 SubPanel tests pass.
- Opening an inbox destination does not resolve its football decision; 37 inbox tests pass.
- Updated full frontend checkpoint: 229 files / 1,715 tests pass; production web build passes. Final release gates remain required.
- Isolated Rust target checks pass: six medical-diagnosis tests, one invalid-fixture settlement regression, and four typed/live tactical-instruction tests. Full backend release gates remain pending.
- Live tactical controls cover nine engine settings, queue individual instructions, use neutral defaults, and disable while pending or finished. Two live integration tests and four shared-panel/payload tests pass; production web build passes.
- Post-match medical reports now use shared diagnoses, translated report parameters, player/fixture context and duplicate-event protection; three post-match regression tests pass, including preservation of a more serious existing injury.

- Mobile follow-up: persistent score header at all viewport widths and safe-area spacing on all four sides; layout regression passes. Physical-device checks remain pending.
- Sidebar simulation, formation, play-style and substitution commands disable at full time and while pending; full-time regression passes.
- Shared decision dialog now has an accessible name, a 44px close target, Escape dismissal, focus containment and focus restoration; keyboard regressions pass.
- Header tactical shortcut opens the existing engine-backed instruction panel; integration regression passes.
- Current environment lacks Cargo/Rust; full backend, Android packaging, signing and device gates remain pending.

## Completion rules

Each proposal needs a working integration and applicable tests or an explicit verified existing implementation. Related changes may share infrastructure, but features must not be marked complete merely because a helper or UI placeholder exists. Audit proposals need recorded results and fixes for findings. Physical-device validation must be reported separately from automated/package checks.
