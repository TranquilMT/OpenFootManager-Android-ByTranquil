# 0.7.5 Matchday redesign — authorised programme

User goal: understandable mobile matches, a combined 11-v-11 pitch, commentary that follows play,
and Football Manager-style tactical control. Requested target: at least 500 meaningful commits
in reviewed batches. Commit count is tracked separately from completed features and release readiness.
No empty commits or splitting a single edit simply to increase the count.

## Batch programme

Each workstream targets 25 independently reviewable changes, with its actual backlog refined from
source audits, failing regression tests and mobile verification. These are budgets, not claims of delivery.

| Batch | Focus | Acceptance |

## Release gates

- Tests cover new behaviour before implementation; all locales updated.
- No fabricated continuous player coordinates: the current engine exposes formations, ball zones and events.
- Preserve player natural positions and XI slot ordering.
- Validate on mobile viewport sizes with long translated team names and high text scaling.
- Complete frontend preflight and full Rust tests/Clippy against the release source.
- Compare APK identity with the user's actual installed baseline; the 0.7.4 installation report remains unresolved.
- Ship a signed update, full source and SHA-256 checksums only after release gates pass.

## Progress

Foundation batch: compact scoreboard; combined tactical pitch; persistent reached-event commentary;
bounded history scroll; consolidated controls; portrait/landscape layout classes; cancelled delayed
phase navigation and ignored in-flight responses after leaving the screen.

Local frontend preflight passed: 1,930 tests in 251 files, build, formatting, lint, translations,
portrait and quality guards. This batch adds 15 tests over 0.7.4. No backend changes in this batch.
Actual visual viewport verification, engine animation work and Android installation remain open.
No new APK published. The 500-commit programme is not complete.

## Continuation batch — 11 to 25 / 500

14 commits in this continuation: 13 source/test changes plus this verification record and
reduced quality baseline. Counted from `f37dd97` (the parent of the programme's first commit).
The target remains 500; these counts do not indicate feature completion or APK readiness.

Delivered:

- Latest action respects the commentary preference, identifies the acting club and keeps the
  player name available in concise mode.
- Yellow-card and entered-substitute indicators preserve player numbers and XI slots.
- Pitch action highlights expire after their recorded minute and are scoped to the event's side.
- Unknown ball zones disappear safely; recorded zone changes interpolate with reduced-motion support.
- Malformed formations, including fractional and infinite line counts, fall back without a crash.
- Invalid/unallocated jerseys use readable initials, including non-Latin names.
- The scoreboard reports paused while the manager's decision workspace stops playback.
- Late tactical results cannot publish into a disposed match view; queued decisions check lifecycle
  and eligibility before sending further instructions.
- Detail tabs now have a separate component, with focus-wrap and speech-control regression coverage.

Validation: full frontend preflight passed on 2026-10-11: **1,954 tests in 253 files**, production
build, formatting, lint, locale coverage (in the test suite), portrait guard and quality ratchet.
24 new regression tests compared with the 11-commit foundation. No backend code or serialized
save fields changed. Rust tests/Clippy, mobile visual checks, native performance, signing and
update installation were not verified in this continuation. No APK was produced.
