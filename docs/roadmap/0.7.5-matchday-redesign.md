# 0.7.5 Matchday redesign — authorised programme

User goal: understandable mobile matches, a combined 11-v-11 pitch, commentary that follows play,
and Football Manager-style tactical control. Requested target: at least 500 meaningful commits
in reviewed batches. Commit count is tracked separately from completed features and release readiness.
No empty commits or splitting a single edit simply to increase the count.

## Batch programme

Each workstream targets 25 independently reviewable changes, with its actual backlog refined from
source audits, failing regression tests and mobile verification. These are budgets, not claims of delivery.

## Release gates

- Tests cover new behaviour before implementation; all locales updated.
- No fabricated continuous player coordinates: the current engine exposes formations, ball zones and events.
- Preserve player natural positions and XI slot ordering.
- Validate on mobile viewport sizes with long translated team names and high text scaling.
- Complete frontend preflight and full Rust tests/Clippy against the release source.
- Compare APK identity with the user's actual installed baseline; the 0.7.4 installation report remains unresolved.
- Ship a signed update, full source and SHA-256 checksums only after release gates pass.

## Continuation milestone: 100 commits

39 source/test commits and this verification record bring the programme to 100 commits
from `f37dd97` on `feat/0.7.5-matchday-redesign`.

Delivered:

- Recorded attacking sequences become replay clips, with key and extended selection.
  Key clips cover goals, penalties, dismissals, injuries, woodwork, world-class saves and
  valid high-probability chances. Extended clips also cover routine shots and bookings.
- Buildup separates possession changes, restarts and phase markers, with bounded action
  count and gaps. Future/invalid clocks never enter the replay catalogue. Clip identity
  remains stable across growing histories, including duplicate same-minute incidents.
- Shootout kicks have isolated clips and never inflate reconstructed match scores.
  Historical scores require a start marker; incomplete recordings do not invent a score.
- A dedicated live Highlights tab offers clips with clocks, club and player names.
  Key/extended modes filter the catalogue; commentary-only mode shows reached event history.
- The viewer has independent play/pause, previous/next action controls, direct seeking,
  keyboard navigation, focus containment/restoration and Escape dismissal. Selecting a clip
  freezes its source snapshot so future match updates cannot rewrite the replay.
- Recorded ball zones animate between observations with reduced-motion support. Narration,
  actors and valid recorded chance probability follow the selected action. Background surfaces
  suspend replay clocks; changing clips resets playback.
- Open replays hold live simulation, decision controls and live spoken commentary. Closing
  the viewer releases replay ownership; post-match highlights need no engine commands.
- Live detail rendering and goal-source analysis are isolated from their parent screens.
  All highlight labels are translated into the 12 supported locales.

Scope: these are manually selected recorded-action replays and highlight browsing modes.
Automatic highlight-driven simulation skipping, exact player runs, pass receivers and detailed
ball trajectories require further engine telemetry and playback integration. Zone transitions
represent recorded observations, not reconstructed continuous tracking. No new engine/save
fields or backend changes were made in this batch.

Validation on 2026-10-11: full `npm run preflight` passed, **2,038 tests in 283 files**,
including 43 additional regression cases. Formatting, lint, locale coverage, portrait diversity,
quality ratchet, TypeScript and production build passed. No quality debt increased; the
oversized TypeScript aggregate fell by 49 lines, and the baseline records the reductions.
Device layout/performance checks, Rust tests/Clippy and signed APK installation remain
unverified. This is a published development milestone, not an APK release.
